# NAVEEN KARAN R S — Embedded Firmware Engineer Portfolio

> Bridging bare-metal silicon, real-time operating systems, and intelligent edge nodes.

A modern, interactive 3D engineering portfolio showcasing embedded firmware development, real-time operating systems (FreeRTOS, QNX), industrial automation (STM32, MODBUS, CAN-bus), IoT architectures, and aerospace systems.

## 🛠️ Technology Stack
- **Firmware & Embedded Systems**: Embedded C, C++, ARM Cortex-M (STM32 F1/F4), ESP32, AVR, FreeRTOS
- **Protocols & Buses**: CAN / CAN-FD, UART/USART, SPI, I2C, MODBUS RTU (RS-485), MQTT
- **Frontend & 3D Interactive Graphics**: React, Three.js, WebGL, Tailwind/CSS3, Lucide Icons
- **Tooling & Build**: Vite, PlatformIO, STM32CubeIDE, Keil MDK, Logic Analyzers

## 📦 Local Setup & Development
```bash
# Clone the repository
git clone https://github.com/naveenkaranrs/naveenrsportfolio.git

# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
